# Wolf: Sideways — 한베 루트 재제작 기획 v0.1

> 시공의 샛길로 빠진 아시나.
> 임무 없는 늑대가, 누군가를 **그냥 찾아가는 법**을 배우는 이야기.

- 메인 공략: **한베** (조연: 쿠로, 겐이치로, 에마, 잇신, 조각가)
- 분량 목표: 1회차 20~30분, 7일(낮/밤)
- 그래픽: 2D 흑백 하프톤 픽셀 + 포인트 컬러 1색 + 소형 전신 스프라이트
- 엔진: 기존 Twine/SugarCube 유지

이 문서는 `WOLF_CONTEXT.md`와 `Wolf_Purgatory_Rework.md`보다 **우선한다.**
엔딩 4분류(End / True / Bad / Shura)와 한베 보이스(`CHARACTER_VOICE.md`)는 그대로 가져온다.
갈대밭은 본편에서 빼고 「불사 엔딩 이후」 히든 에필로그 후보로 보관한다.

---

## 1. 이 루트가 하는 일

한베는 죽지 못한다. 늑대는 죽어도 돌아온다.
둘 다 "끝"을 제대로 가져본 적이 없다.

원작에서 한베의 이야기는 늑대가 불사참으로 그를 끝내주는 것으로 닫힌다.
Sideways는 그 직전에서 갈라진다.

> **늑대가 그를 베는 손이 아니라, 그를 찾아가는 사람이 될 수 있는가.**

커플 감정은 대사가 아니라 **거리**로 쌓는다.
처음엔 검 하나 거리에서 마주 서고, 마지막엔 등을 맡긴다.

## 2. 핵심 장치

### 2-1. 거리 `$hanbeiDist` (0~4)

호감도 숫자를 보여주지 않는다. 대신 지문과 스프라이트 위치가 바뀐다.

| 값 | 이름 | 화면 연출 | 지문 키워드 |
|---|---|---|---|
| 0 | 대련 거리 | 화면 양 끝, 서로 마주 봄 | 익숙한 거리 |
| 1 | 검 하나 거리 | 반 칸 가까이, 한베만 늑대 쪽을 봄 | 검끝이 닿지 않는 거리 |
| 2 | 곁에 앉는 거리 | 같은 마루/흙바닥에 나란히 앉음 | 바람 소리만 |
| 3 | 어깨 닿는 거리 | 스프라이트가 겹치기 직전 | 체온, 짚 냄새 |
| 4 | 등을 맡기는 거리 | 서로 등을 대고 앉음 (새벽빛) | 뒤를 보지 않아도 |

- 날마다 최대 +1. 오르면 화면 끝에 한 줄만 붙인다: `거리가 조금 줄었다.`
- 숫자는 절대 노출하지 않는다.

### 2-2. 균열 `$hanbeiCrack` (0~3)

늑대가 **솔직해진 횟수**. "문제없다" 대신 "아프다"고 말하거나, 한베의 농담을 넘기지 않고 붙잡을 때 오른다.
`WOLF_CONTEXT`의 "갈등" 축을 단순화한 것. 다정하기만 하면 True End에 닿지 못한다.

### 2-3. 침묵 선택지

늑대 대사의 절반은 `…`다. 같은 `…`를 **어떤 침묵인지** 고르게 한다.

```text
[늑대]
…

▸ 시선을 피한다      (거리 유지, 한베가 놀림)
▸ 곁에 앉는다        (거리 +)
▸ 고개를 끄덕인다    (균열 +, 한베가 당황)
```

한베는 늑대의 침묵을 읽고 반응한다. 이게 이 루트의 티키타카다.

### 2-4. 안 간 날도 기록된다

낮에 한베 대신 다른 곳에 가면, 다음 방문 첫마디가 바뀐다.

```text
[한베]
어제는 안 오더군.
……아니, 기다렸다는 말은 아니고.
```

한베를 찾아간 날이 4일 미만이면 7일차 대신 「멀어지는 End」로 간다.

### 2-5. 인연 기억 (기록장 축소판)

기록장은 탭 하나만 남긴다: **인연 기억**.
하루에 한 장, 그날의 대사 한 줄과 1-bit 삽화가 카드로 남는다.
잠긴 카드는 제목만 `???`.

### 호칭 변화

- 1~3일차: "자네"
- 4일차 술자리에서 처음으로 "너"가 한 번 샌다. 바로 "자네"로 고친다.
- 6일차 이후: "너"가 섞인다. (`CHARACTER_VOICE.md` 한베 호칭 규칙)

### 낮 허브 선택

```text
늑대는 어디로 향하나?

▸ 훈련장 (한베)
▸ 아시나 성 (쿠로)          ← 주종/가족 축. 커플 축 아님
▸ 성 아래 길 (겐이치로)     ← 라이벌 조연
▸ 절에 머문다 (조각가/에마)
```

다른 곳은 짧은 단막 1~2개만 만든다. 그날 한베를 안 간 사실이 다음 날 반영된다.

## 4. 엔딩

7일차 최종 선택 + `$hanbeiDist` + `$hanbeiCrack`으로 갈린다.

| 엔딩 | 분류 | 조건 | 원본 | 마지막 장면 |
|---|---|---|---|---|
| **새벽의 대련** | True End (선택한다) | 거리 4 + 균열 2 이상 + **베지 않는다** | `_NoCut_Result` | 늑대가 처음으로 거절한다. "베지 않는다. 대신 내일도 온다." 둘이 등을 대고 앉은 채 새벽이 온다. 포인트 컬러가 처음으로 화면 전체에 번진다 |
| **빈자리** | End (남아 있다) | 거리 3 이상 + **침묵** | `_Silence_Result` | 한베가 곁의 빈자리를 그대로 둔다. 늑대는 대답하지 못했지만 매일 그 자리로 간다 |
| **언젠가의 끝** | End (원작 오마주) | **언젠가 베어주겠다고 약속** | `_Mercy_Result` | 원작 결말을 미룬 약속. 언젠가 끝날 대련이 둘 사이에 놓인다. 씁쓸하지만 늑대는 아직 자신이다 |
| **잘 맞는 칼자루** | Bad End (선택당한다) | 거리 2 이하 + **검을 쥔다** | `_Sword_Result` | 칼자루가 너무 잘 맞는다. 늑대는 다시 "베는 손"으로 쓰인다 |
| **멀어지는 날들** | End | 한베 방문 4일 미만 | 신규 | 훈련장에 발자국이 늘지 않는다. 한베는 여전히 거기 있다. 그게 더 아프다 |
| (히든) **수라** | Shura End | 조연 루트에서 수라 전조 누적 시 | `shura.twee` | 2회차 이후 개방 |

## 5. 그래픽 가이드

- **구현**: 외부 이미지 없이 `sideways/art.js`가 JS 캔버스로 직접 그린다.
  - 배경 256×144, 회색 10단계. 그라데이션은 평평한 띠 + 경계에만 Bayer 디더링.
  - 스프라이트 32×44 + 1px 외곽선, 숨쉬기 2프레임. 배경과 같은 픽셀 배율로 확대하고, 발은 배경별 지면선(`ground`)에 맞춘다.
  - 배경별 입자: 훈련장 낙엽, 절 먼지, 밤·꿈 재. `<<fx "arrow">>`는 화살이 화면을 가로지른다.
  - 자세: 한베 shoulder / draw / rest / stand / sit, 늑대 stand / guard / sit (sit은 3일차용).
- (이전) 기존 흑백 하프톤 배경(`assets/backgrounds/TrainingArea.png`, `Temple.png`)은 참고용으로만 둔다.
- **포인트 컬러 1색**: 등불 주황 `#E08A3C` (가칭).
  - 1~3일차: 화면에 없음
  - 4일차 술잔에서 처음 등장 (작은 점 하나)
  - 5일차 마스크 장면: 한베의 눈가 주변에만
  - True End: 새벽빛으로 화면 전체에 번짐
  - 수라는 대신 붉은색 `#9E2B25`
- **스프라이트**: 높이 48~64px 전신. 표정 대신 자세로 감정 표현.
  - 한베: 검을 어깨에 걸침 / 검을 바닥에 내려놓음 / 앉음 / 등 돌림 / 마스크에 손
  - 늑대: 서 있음 / 앉음 / 고개 돌림 / 검자루에 손 / 등을 맞댐
  - 실루엣만으로 원작 캐릭터를 알아볼 수 있게: 한베 투구 장식, 늑대 목도리, 겐이치로 활
- **인연 기억 카드**: 1-bit 삽화 7장 (+ 엔딩 5장). 손으로 그리거나 직접 찍는 것을 권장.

## 6. 구현 메모

- 대사 한 줄마다 passage를 만들지 않는다. 한 장면 = 한 passage로 두고, passage 안에서 클릭하면 다음 줄로 넘어간다.
  - 현재 한베 1~3단계만 120개 이상 passage → 장면 단위면 약 15개.
- 새 본편은 **별도 스토리** `sideways/` 폴더에 있고 `sideways.html`로 빌드한다. 기존 `src/`, `index.html`은 문장 출처로만 쓰고 건드리지 않는다.
  - 빌드: `TWEEGO_PATH=tools/tweego tools/tweego/tweego -o sideways.html sideways` (`build:sideways`)
  - `sideways/engine.js`: 장면 진행 매크로 — `<<n>>` `<<h>>` `<<w>>` `<<note>>` `<<caption>>` `<<choices>>`, 연출 `<<bg>>` `<<stage>>` `<<fx>>` `<<memory>>` (사용법은 파일 머리 주석)
  - `sideways/art.js`: 배경 4종(training / temple / night / dark)과 한베·늑대 스프라이트를 **JS 캔버스로 직접 그린다.** 외부 이미지 없음
  - 키: 클릭·스페이스·엔터로 진행, 숫자 키로 선택지
- 변수는 최소화:
  - `$day` (1~7), `$hanbeiDist`, `$hanbeiCrack`, `$hanbeiVisits`, `$skippedYesterday`, `$memories` (Set)
- `index.html` 직접 수정 금지, 빌드는 기존 tweego 명령 그대로.

## 7. 1일차 첫 장면 초안

> 표기: `[스프라이트: …]`는 화면 연출, `▸`는 선택지.
> 원본 docx `Hanbei01_*`의 문장을 거의 그대로 살리고, 거리·침묵 선택지만 새로 넣었다.

### D1_Training (훈련장, 낮)

```text
[배경: 훈련장]
[스프라이트: 한베 — 화면 오른쪽 끝, 검을 어깨에 걸침 / 늑대 — 왼쪽 끝]

나레이션:
황폐한 절에서 조금 떨어진 공터.
흙바닥에는 수없이 많은 발자국이 남아 있다.

그리고.
예상했던 사람이 있었다.

나레이션:
그는 검을 어깨에 걸친 채 손을 흔들었다.
마치 오래된 친구를 맞이하는 것처럼.

[한베]
오.
왔나?

[늑대]
…

  ▸ 시선을 피한다
  ▸ 고개를 끄덕인다
```

**시선을 피한다**

```text
[한베]
뭐야, 그 얼굴.
오늘도 날 베러 온 거 맞구만.
```

**고개를 끄덕인다** — `$hanbeiCrack += 1`

```text
[한베]
……오.
대답을 다 하는군.

나레이션:
한베는 잠깐 말을 잃었다.
아주 잠깐.

[한베]
하하하! 오늘 무슨 날인가?
```

### 수치가 오르는 곳

- **거리** (최댓값 기준, 놓쳐도 뒤에서 따라잡을 수 있음)
  - 1일차 한 걸음 다가간다 → 1 / 2일차 미안하다 → 1
  - 3일차 곁에 앉는다, 4일차 잔을 받는다, 5일차 손을 멈춘다 → 2
  - 5일차 가면을 더듬는다 → 3
  - 7일차 나는 가지 않는다 (거리 3 이상일 때) → 4
- **균열** (최대 3): 1일차 끄덕임, 2일차 아프다/잘 모르겠다, 3일차 밤 "미련이다", 4일차 얼굴을 본다/에마 편, 5일차 손을 멈춘다, 6일차 모르겠다/죽고 싶은 건가/베고 싶지 않다
- **수라**: 2일차 대련을 계속한다/불사는 무기다, 6일차 임무다/검자루에 손/밤에 검을 쥔다
- **색**: 4일차 술잔(또는 5일차 방문)부터 `$color`. 늑대의 목도리가 원작의 주황으로 돌아온다

### 결말 조건 (7일차 해 질 녘)

| 결말 | 조건 |
|---|---|
| True End 「새벽의 대련」 | 베지 않는다 + 거리 4 + 균열 2 이상 |
| End 「빈자리」 | 아무 말도 하지 않는다, 또는 조건이 모자란 채 베지 않는다 |
| End 「언젠가의 끝」 | 그 약속을 받아들인다 |
| Bad End 「잘 맞는 칼자루」 | 검을 확인한다 (거리 2 이하 또는 수라 2 이상일 때만 보임) |
| Shura End 「베어낸다」 | 검을 뽑는다 (수라 3 이상일 때만 보임) |
| End 「멀어지는 날들」 | 6일 동안 한베를 찾아간 날이 4일 미만 |

본 결말은 브라우저에 기록되어(SugarCube `memorize`) 타이틀과 인연 기억 패널에 표시된다.
